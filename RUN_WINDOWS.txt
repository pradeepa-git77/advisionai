ADVISION AI — WINDOWS / VS CODE QUICK START

1) Extract this ZIP and open the AdVision-AI-Dataset-Integrated folder in VS Code.

2) BACKEND — open a terminal and run these commands one by one:
   cd backend
   py -3.13 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

   If .venv already exists, skip the venv creation line.
   This uses the virtual-environment Python directly and does not require Activate.ps1.
   API docs: http://127.0.0.1:8000/docs
   Health check: http://127.0.0.1:8000/api/health

3) FRONTEND — open a SECOND terminal:
   cd frontend
   npm.cmd install
   npm.cmd run dev

   Open the Local URL printed by Vite (normally http://localhost:5173).

4) TEST THE MODES
   - Image Analysis: upload image(s), no CSV required.
   - Campaign Performance: upload image(s) and a valid campaign CSV.
   - Bundled dataset: click the Srishti dataset button (included data is synthetic).

TROUBLESHOOTING
- Keep both terminals open.
- If VS Code shows missing imports, press Ctrl+Shift+P > Python: Select Interpreter and select backend\.venv\Scripts\python.exe.
- If the backend port is busy, stop the old process with Ctrl+C before restarting.
- Do not commit .venv or node_modules to Git.
- The included 150 images and campaign metrics are synthetic benchmark data, not real verified campaign results.
